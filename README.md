# WooCommerce Telegram Order Notifications

Плагин отправляет уведомления об оплаченных заказах WooCommerce в Telegram через Action Scheduler. Он работает через Telegram Bot API напрямую или через HTTPS-прокси и совместим с HPOS. В уведомлении есть номер, сумма, статус и ссылка на заказ в админке. Контактные данные покупателя в сообщение не включаются.

## Установка

1. Поместите каталог плагина в `wp-content/plugins/` и активируйте его. Нужны WordPress 6.5+, PHP 8.0+, WooCommerce и MySQL или MariaDB с поддержкой именованных блокировок.
2. Откройте **Настройки → WooCommerce Telegram** или нажмите **Настройки** в строке плагина. Введите токен бота и ID чата. Для личного чата сначала запустите бота, для группы или канала добавьте бота и дайте ему право писать.
3. Для подключения через Worker укажите базовый HTTPS-адрес доверенного прокси, который принимает пути Bot API вида `/bot<TOKEN>/sendMessage` и возвращает JSON Telegram. Прокси получает токен как часть запроса. Для прямого подключения оставьте поле пустым. Сохраните настройки.
4. Проверьте подключение командой `wp wc-telegram check`. Для тестового сообщения в настроенный чат запустите `wp wc-telegram check --send-test`. Если другой плагин уже пересылает заказы в этот чат, отключите пересылку именно этих уведомлений при переключении.

Для серверной конфигурации доступны `WCTON_BOT_TOKEN`, `WCTON_CHAT_ID` и `WCTON_PROXY_URL`. Для каждого поля приоритет имеет константа в `wp-config.php`, затем переменная среды, затем значение из админки. Поля с серверным значением недоступны для редактирования. Токен, введённый через админку, хранится в базе WordPress. Оставьте поле токена пустым при повторном сохранении, чтобы сохранить текущий токен.

## Повторная отправка

`wp wc-telegram enqueue <ID> [<ID>...]` ставит существующие оплаченные заказы в очередь по внутренним ID WooCommerce. Очередь видна в **WooCommerce → Статус → Запланированные действия**, группа `wc-telegram-orders`.

Плагин сохраняет ID принятого Telegram сообщения в метаданных заказа. При ограничении частоты запросов он планирует до трёх повторов с учётом `retry_after`. Если результат неизвестен (например, соединение оборвалось после отправки запроса), сначала проверьте чат. Если сообщения там нет, поставьте заказ в очередь с флагом `--retry-unconfirmed`. Telegram Bot API не предоставляет ключ идемпотентности для `sendMessage`.
