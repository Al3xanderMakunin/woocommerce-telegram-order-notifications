# WooCommerce Telegram Order Notifications

Плагин отправляет уведомления о заказах WooCommerce любого статуса, включая неоплаченные, в Telegram через Action Scheduler. Он работает через Telegram Bot API напрямую или через HTTPS-прокси и совместим с HPOS. Уведомление оформлено как письмо WooCommerce о новом заказе. В нём есть номер, дата и ссылка на заказ, позиции с выбранными параметрами, количеством и суммой до скидки, а также подытог, скидка, доставка, способ оплаты, итог и платёжный адрес с контактами покупателя. Если уведомление превышает лимит Telegram, все данные приходят в текстовом файле. Черновики блочного оформления попадают в очередь после оформления заказа.

## Установка

1. Поместите каталог плагина в `wp-content/plugins/` и активируйте его. Нужны WordPress 6.5+, PHP 8.0+, WooCommerce и MySQL или MariaDB с поддержкой именованных блокировок.
2. Откройте **Настройки → WooCommerce Telegram** или нажмите **Настройки** в строке плагина. Введите токен бота и список чатов. Укажите числовые ID или публичные имена в формате `@username`. Разделяйте значения переносами строк, запятыми или пробелами. Для личного чата сначала запустите бота, для группы или канала добавьте бота и дайте ему право писать.
3. Для подключения через Worker укажите базовый HTTPS-адрес доверенного прокси, который принимает пути Bot API вида `/bot<TOKEN>/sendMessage` и возвращает JSON Telegram. Для длинных заказов прокси должен также передавать запросы к `sendDocument` с телом `multipart/form-data`. Прокси получает токен как часть запроса. Для прямого подключения оставьте поле пустым. Сохраните настройки.
4. Проверьте подключение командой `wp wc-telegram check`. Для тестового сообщения во все настроенные чаты запустите `wp wc-telegram check --send-test`. Если другой плагин уже пересылает заказы в этот чат, отключите пересылку именно этих уведомлений при переключении.

Для серверной конфигурации доступны `WCTON_BOT_TOKEN`, `WCTON_CHAT_ID` и `WCTON_PROXY_URL`. В `WCTON_CHAT_ID` можно указать несколько чатов, например `-1001234567890,@my_channel`. Для каждого поля приоритет имеет константа в `wp-config.php`, затем переменная среды, затем значение из админки. Поля с серверным значением недоступны для редактирования. Токен, введённый через админку, хранится в базе WordPress. Оставьте поле токена пустым при повторном сохранении, чтобы сохранить текущий токен.

## Повторная отправка

В разделе **Настройки → WooCommerce Telegram → Ручная отправка** введите внутренний ID заказа и нажмите **Отправить уведомление**. Плагин отправляет уведомление во все настроенные чаты, даже если действие для этого заказа ещё в очереди или Telegram уже принял уведомление. При неизвестном результате предыдущей попытки проверьте чаты, указанные в ошибке, и поставьте галочку под полем ID, если хотите повторить отправку.

`wp wc-telegram enqueue <ID> [<ID>...]` ставит существующие заказы в очередь по внутренним ID WooCommerce. Очередь видна в **WooCommerce → Статус → Запланированные действия**, группа `wc-telegram-orders`.

Плагин сохраняет ID принятого Telegram сообщения в метаданных заказа отдельно по каждому чату. При ограничении частоты запросов он планирует до трёх повторов для соответствующего чата с учётом `retry_after`. Если результат неизвестен (например, соединение оборвалось после отправки запроса), сначала проверьте чат. Если сообщения там нет, поставьте заказ в очередь с флагом `--retry-unconfirmed`. Telegram Bot API не предоставляет ключ идемпотентности для отправки сообщений.
